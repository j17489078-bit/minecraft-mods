How to Install

Follow these in order. Skip nothing.

STEP 01

Install the mod loader

Download the Fabric installer and run it. Pick Minecraft 1.21.1 and hit Install.

STEP 02

Open your mods folder

Press Win + R, paste the path below, hit Enter. On Mac: ~/Library/Application Support/minecraft/mods

STEP 03

Drop the mods in

Download every .jar from this page and drag them straight into that folder. Don't unzip them.

STEP 04

Launch & check

Open the launcher, select the Fabric profile, and start the game. If it crashes, tell me which mod it names.

⚠️

Version match matters. Every mod must be for Minecraft 1.21.1 and the Fabric loader. A single mismatched mod will crash the game on startup.
